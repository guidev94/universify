# Projeto: WV_Todoz Premium Redesign

## Visão Geral
Transformar o site institucional da WV_Todoz em uma vitrine tecnológica de alto padrão, utilizando animações de ponta e UX refinada para atrair contratos de alto valor.

## Objetivos
1. **Percepção de Valor**: Elevar a marca para o patamar de "Elite Tech Agency".
2. **Storytelling Visual**: Usar animações para explicar processos complexos de desenvolvimento.
3. **Conversão**: Facilitar o contato para leads qualificados.
4. **Performance**: Garantir carregamento instantâneo e fluidez (Core Web Vitals).

## Stack Tecnológica
- **Frontend**: HTML5, Tailwind CSS, GSAP (ScrollTrigger, Flip, Observer), Lenis (Smooth Scroll).
- **Interações**: Framer Motion (para estados de UI).
- **Arquitetura**: Component-based (preparado para WordPress).

## KPI de Sucesso
- Feeling de "Site de R$ 50k+".
- Retenção de usuário (Dwell Time) aumentada via interatividade.
