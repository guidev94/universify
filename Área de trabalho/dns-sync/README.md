# DNS Sync

Aplicativo Flutter para sincronização de DNS e gerenciamento de proxies gratuitos, com visual moderno inspirado no Airbnb.

## Desenvolvido por
**Aquinodev**

## Funcionalidades
- **Sincronização DNS:** Alterne entre Google DNS e Cloudflare com um toque.
- **Proxies Gratuitos:** Lista atualizada de proxies via API (ProxyScrape).
- **Interface Moderna:** Design limpo, minimalista e responsivo.
- **Animações Fluidas:** Experiência de usuário aprimorada com animações GSAP-style.

## Tecnologias Utilizadas
- Flutter
- Riverpod (Gerenciamento de Estado)
- Google Fonts (Inter)
- Flutter Animate
- ProxyScrape API

## Como executar
1. Certifique-se de ter o Flutter instalado.
2. Clone o repositório.
3. Execute `flutter pub get`.
4. Execute `flutter run`.
