# Feature Spec: Elite Speed & Video Streaming Test, Real ISP Detection & Result Sharing

## Overview
Elevate Sync DNS's testing capabilities to match and exceed tools like Ookla Speedtest and Fast.com:
1. Real ISP and network provider detection (Claro, Vivo, Starlink, TIM, etc. with ASN, IP, country flag, city).
2. Comprehensive Video Streaming Test measuring TTFB, buffering ratio, and maximum playback resolution (4K 2160p, 1080p FHD, 720p HD, 480p SD).
3. Native Sharing System to export and share formatted test results cards across messaging apps and social media.
4. Seamless segmented UI tabs (Internet Speed vs. Video Streaming Test) with cybernetic visual charts.

## Requirements Traceability
- **REQ-ISP-1:** Detect user's ISP, ASN, country, city, and connection type (Wi-Fi, 5G, 4G LTE) automatically.
- **REQ-VIDEO-1:** Real Video Streaming Test measuring buffering latency, chunk throughput, and assigning a video streaming grade (4K Ultra HD ready, 1080p Full HD, 720p HD, 480p SD).
- **REQ-SHARE-1:** Share formatted test results badge/summary with 1 tap via native Android/iOS share sheets.
- **REQ-UI-SPEED-1:** Segmented navigation (Velocidade vs. Teste de Vídeo) with animated chart rendering and high-contrast typography.
- **REQ-TEST-1:** 100% automated test coverage across all new engines and UI widgets.
