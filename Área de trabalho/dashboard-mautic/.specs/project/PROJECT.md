# Project: Google Ads Dashboard for WordPress

## Vision
A high-end WordPress plugin that provides a performance dashboard directly in the wp-admin, integrating dynamically with Google Ads API.

## Core Goals
- Replicate the visual quality of Google Ads dashboards (as seen in provided images).
- Dynamic data fetching from Google Ads API.
- Filterable views (Account, Campaign, Ad Group, Device, Date Range).
- KPIs and charts for Impressions, Clicks, Conversions, CTR, and CPC.
- Clean, responsive UI using modern frontend standards.

## Tech Stack (Proposed)
- **Backend:** PHP (WordPress Plugin API), Google Ads PHP SDK.
- **Frontend:** JavaScript (React or Vue.js), Chart.js or Recharts, Tailwind CSS.
- **Data:** Google Ads Query Language (GAQL).
