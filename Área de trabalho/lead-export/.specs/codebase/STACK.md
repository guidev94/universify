# Tech Stack
- **Language:** Python 3.12+
- **Web Framework:** Flask
- **Database:** SQLite (with WAL mode enabled)
- **Frontend:** HTML, JavaScript (jQuery), Tailwind CSS (via templates)
- **Task Scheduling:** Custom `scheduler.py` and `pipeline.py`
- **Crawling:** Python-based crawlers in `crawler/` directory
- **Testing:** Pytest, Playwright for E2E
