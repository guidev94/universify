# Directory Structure

- `/`: App entry point, config, and main logic.
- `/blueprints/`: Route modules for different app sections.
- `/crawler/`: Lead extraction and processing modules.
- `/data/`: SQLite database files and logs.
- `/exports/`: Generated export files (CSV, XLSX).
- `/static/`: CSS, JS, and image assets.
- `/templates/`: Jinja2 HTML templates.
- `/tests/`: Unit and E2E tests.
- `/venv/`: Python virtual environment.
